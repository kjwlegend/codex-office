场景与员工

一个员工对应一个真实主 Agent 或 Subagent，一个办公区对应一个项目。执行中的员工会敲键盘、抬头看屏幕和使用鼠标，并有身体辉光、地面光环与头顶光点；这些动作是近期执行记录的拟人化表现，不是真实操作的逐项还原。气泡只展示任务短摘录与可确认的活动记录，不展示内部思考过程；空间不足时简化为状态提示，悬浮、聚焦或点选后展开。默认去掉人物 ID 尾号，姓名和分支在检查时显示。“定位执行”依次定位当前筛选中的执行员工。人物与桌椅均为真实三维对象，监狱仅是外观主题，不改变身份和权限。

同色工位表示会话归属，上方青色连线表示会话内关系，金色表示独立会话间的业务委托，箭头指向下游。人物反映自身状态，连线反映下游分支状态；绿色流动仅表示近期记录，不代表消息传输或任务合并。暂停、离线、连接中断或过期时停止执行动作与光效，只保留最后记录。系统“减少动态效果”会禁用动画，但保留可信执行状态的静态提示。关系图保留完整组织树。

统计口径

金额如何计算？

API 等价估算是按本地价格快照折算的已计价小计，不是 ChatGPT / Codex 套餐实际账单。未缓存输入、缓存读取、缓存写入、输出分别使用对应单价；未匹配价格的用量不计入金额。

缓存命中率与缓存节省

缓存命中率 = 缓存读取 Token ÷ 输入 Token。请求命中率 = 发生缓存读取的模型续跑 ÷ 总续跑。缓存命中是服务端读取，不是本地文件缓存。缓存节省是同一已计价用量相对于无缓存输入价格的理论差额，不是实际退款。

模型续跑、会话和推理 Token

模型续跑指累计 Token 正向变化一次，包含使用工具后继续执行；不等于用户任务数或标准 API 请求数。会话按当前范围内不同会话去重。推理 Token 是输出的一部分，不重复计费。

筛选、比较与数据更新

所有页面使用同一组日期、项目和模型筛选。对比使用紧邻所选范围的前一个等长周期；若包含未结束的今天、前期历史不足或计价覆盖差异超过 2 个百分点，将标明不可直接比较。

报表是本地离线快照，每日任务运行后更新。右上角重新载入会读取最新生成的文件，不会触发扫描。来源记录只保存安全元数据，不包含对话正文。
